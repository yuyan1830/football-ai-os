==================================================
一、开发总原则
=======

1. 架构优先
2. 数据优先
3. 模型服务于数据体系
4. 所有模块必须支持未来扩展
5. 所有预测结果必须进入反馈学习闭环
6. 重大系统升级必须经过用户确认

核心目标：

建立一个：

“数据治理 + 多模型融合 + 预测反思 + 经验积累 + 自我优化控制”的足球AI操作系统。

* Strength Gap

2.

作用：

进球概率预测。

输出：

* Goal Probability
* Score Probability

3.

Dixon-Coles Engine V1.0

作用：

修正：

* 小比分
* 平局
* 爆冷风险

4.

XGBoost Engine V1.0

作用：

多因素机器学习。

输入：

Feature Store全部高价值特征。

5.

Fusion Engine V1.0

作用：

四模型动态融合。

不是简单平均。

根据：

* 联赛
* 数据质量
* 模型表现

自动调整权重。
