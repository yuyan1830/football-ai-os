Legacy不是废代码。

必须：

不能根据文件名判断重复。

和

elo_model.py


不能因为名字相同认为重复。


必须检查：

- 类
- 函数
- 调用关系
- 数据流
- 配置
- 测试



--------------------------------------------------


原则3：

最终必须形成：

唯一运行路径。
